# Fides Record Loop — production MVP asset rules

Record Loop is the locked Fides mark. The vector geometry in this folder is the production MVP master derived from the selected third-round Record Loop direction.

## Required usage

- Default product lockup: Record Loop symbol followed by **Fides**.
- Symbol-only: app icon, favicon, and compact product surfaces.
- App icon: Signal Indigo (`#4357B2`) field, light Record Loop left form, Human Coral (`#E07A64`) right form, pale record center.
- Primary light surfaces use Signal Indigo + Human Coral with Ink (`#1C1D22`) wordmark.
- Dark-background variant uses the supplied dark asset.
- Monochrome uses the supplied one-color asset.

## Clear space and safe area

Use the center-record diameter as the minimum clear space around a standalone symbol or horizontal lockup. Do not place text, rules, icons, or container edges inside that area.

For app-icon and favicon crops, keep the complete mark inside an 80% centered safe area. Platform masks may round the outer app-icon field; never pre-crop the Record Loop symbol itself.

## Do not modify

Do not rotate, stretch, add gradients, add shadows, recolor individual pieces, rearrange the two forms, add a third brand color, or use the mark as a status/error indicator. Human Coral remains a brand accent and is not a destructive-action color.
